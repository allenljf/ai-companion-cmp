# AI 旅伴（AI Companion）功能報告 — Phase 1 & Phase 2

> 本文件為對內報告用途，說明 AI 旅伴功能的完整使用者體驗、與 KKday 的商業價值結合，以及後續延伸方向。內容以非工程視角撰寫。

---

## 一、功能總覽

AI 旅伴是 KKday App 內的 AI 互動功能，讓使用者「擁有一位專屬的 AI 旅遊夥伴」，從認識使用者的旅遊性格開始，一路陪伴到排出一份可執行、可預訂的旅遊行程。

分為兩個階段：

| 階段 | 主軸 | 一句話說明 |
|---|---|---|
| **Phase 1（已上線）** | 認識你 | 建立專屬旅伴 → 玩旅行 DNA 測驗 → 得到旅行人格分析與命定城市 → 生成個人化分享海報 |
| **Phase 2（試驗中）** | 幫你排 | 和旅伴聊天 → 收斂目的地 → 回答偏好問卷 → AI 一次生成完整逐日行程 → 用自然語言隨時修改 → 行程內直接看到可預訂的 KKday 商品 |

## 二、Phase 1 使用者操作流程（旅伴與測驗）

### 步驟 1：建立專屬旅伴
- 使用者從入口進入後，先「捏」出自己的旅伴：選擇**人格特質**（幽默、溫暖、傲嬌…）、**說話風格**（親切、活潑、中二…）、**外觀造型**（性別、髮型、穿著），並幫旅伴**命名**。
- 建立完成後，旅伴會用 AI 生成一段符合其人設的**自我介紹**，讓使用者感受到「這是一個有個性的角色」，而不是冷冰冰的聊天機器人。

### 步驟 2：旅行 DNA 測驗
- 旅伴出題（生活情境式選擇題，AI 會用旅伴的語氣改寫題目），使用者逐題作答。
- 每個選項背後對應旅遊偏好標籤（例如「資深吃貨」「夜貓子」「預算控」）。
- 題目具備防重複機制：玩越多次，出現過的題目越不容易再出現。

### 步驟 3：人格分析結果與命定城市
- 作答完成後，AI 生成專屬分析：**旅行人格稱號**（八種之一，如「私房鑑賞家」）、**命定城市**、亮點標籤、旅伴給你的一句話、三段推薦文。
- 等待分析的過程會逐句播放 AI 的「思考過程」（打字機效果），最後揭曉目的地——把等待時間變成期待感。

### 步驟 4：個人化分享海報
- AI 生成一張**專屬場景圖**（目的地場景，可把使用者捏的旅伴人物合成進畫面），App 端疊上目的地郵戳、標籤插畫與文字，合成完整分享海報。
- 可分享到社群，海報帶 KKday 品牌，具自然傳播效果。

### 步驟 5：社群牆與回顧
- 「其他人也測過」社群牆：瀏覽其他使用者的測驗結果與海報，逆向找旅行靈感。
- 「回顧我的旅行 DNA」：查看自己過去的測驗結果，隨時再分享。

## 三、Phase 2 使用者操作流程（行程規劃）

### 四種進入方式（入口）

| 入口 | 情境 | 體驗重點 |
|---|---|---|
| **從測驗結果繼續** | 剛測完旅行 DNA | 旅伴帶著你的命定城市與人格分析，無縫接續「那就來排這個城市的行程吧」 |
| **帶訂單開場** | 已有即將出發的 KKday 訂單 | 旅伴主動發現「你有即將出發的旅程」，AI 從訂單判斷目的地城市（最多 3 個選項），點一下就從已預訂的旅程開始排 |
| **匯入行程** | 已用 ChatGPT 等其他 AI 排過行程 | 把外部行程貼進來，旅伴看完直接接手，把「別家 AI 的產出」轉化為「KKday 上可執行、可預訂的行程」 |
| **從零開始** | 完全沒想法 | 和旅伴多輪聊天（最多 5 輪），從模糊的想法（「想看海放空」）收斂出一個具體城市 |

### 主流程（以帶訂單開場為例）

1. 點「一起規劃旅遊行程(帶訂單)」→ 旅伴打招呼：「我發現你的訂單中有即將出發的旅程，想從哪個目的地開始？」+ 城市選項
2. 點選城市 → 旅伴生成呼應訂購商品的開場白
3. 回答**偏好問卷**（聊天式一次一題）：天數、預算、節奏、主題、最在意的事、特殊需求（自由輸入，如「帶長輩不想自駕」）
4. AI 一次生成**完整逐日行程**：每天的景點、用餐、交通安排，含精確時間（HH:MM）、景點座標（可開地圖導航）、交通方式圖示
5. **已預訂的訂單自動排入行程**，標上「已預訂」標籤，AI 修改行程時會保護這些項目不被動到

### 行程成果頁功能

- **總覽 / 每日分頁**：總覽看全貌，點某天看當日時間軸細節
- **拖曳排序**：長按行程項目可拖曳交換順序，即時生效
- **KKday 商品卡**：每個景點自動用「城市＋景點名」搜尋 KKday 商品，找到就顯示第一項商品卡＋「還有 N 項相關商品」，點擊直接開搜尋結果頁——**行程裡的每個景點都是導購入口**
- **旅伴 FAB 聊天修改**：右下角旅伴頭像懸浮按鈕（可拖曳擺放位置），點開聊天視窗用自然語言改行程（「下午想加個抹茶體驗」），AI 讀完整段對話脈絡再修改——之前提過「對海鮮過敏」，之後加晚餐就不會排海鮮餐廳
- **儲存我的旅程**：行程存在本地，旅伴首頁可隨時回顧、繼續編輯、繼續請旅伴修改

## 四、與 KKday 結合的商業價值

### 1. 旅伴（角色化 AI）＝ 提升黏著與品牌情感
- 有名字、有個性、有外觀的旅伴，建立的是「關係」而不是「工具使用」。使用者對旅伴的投入（捏角色、命名）本身就是沉沒成本，提高回訪意願。
- 旅伴的語氣貫穿測驗、規劃、修改全程，是 KKday 專屬的品牌角色資產。

### 2. 測驗 ＝ 低成本取得高價值的偏好資料 + 自然傳播
- 使用者「玩」測驗的過程，等於主動告訴我們他的旅遊偏好（吃貨/夜貓/預算控…），這是傳統問卷拿不到的高品質第一方資料。
- 分享海報帶動社群自然擴散，每張海報都是帶 KKday 品牌的個人化廣告。
- 命定城市直接連到「排這個城市的行程」，測驗不是玩完就結束，是漏斗的入口。

### 3. 安排行程 ＝ 從「靈感」到「訂單」的完整漏斗
- 傳統痛點：使用者在別處（Google、小紅書、ChatGPT）做行程研究，來 KKday 只是「下單工具」。AI 旅伴把**行程研究階段留在站內**，決策過程發生在哪裡，訂單就發生在哪裡。
- 行程中的每個景點自動對應 KKday 商品卡，**規劃即導購**：使用者不是「被推銷」，是「行程需要」。

### 4. 挑選城市 ＝ 承接「還沒決定去哪」的最上層流量
- 大部分導購產品只能服務「已經決定目的地」的使用者；城市收斂對話承接的是**連目的地都還沒想好**的最早期需求，這是市場上競爭最少、心智占領價值最高的階段。

### 5. 從訂單安排行程 ＝ 存量訂單的二次變現
- 已買機票/門票/一日遊的使用者，旅程中還有大量未被滿足的空檔。主動說「我發現你有即將出發的旅程」，把**一張訂單擴大成一整趟旅程的多筆訂單**（cross-sell / upsell）。
- 已預訂項目排入行程並受保護，強化「KKday 掌握你的整趟旅程」的心智。

### 6. 客製化修改行程 ＝ 持續互動、持續了解使用者
- 每一次「幫我改」都是一次偏好訊號（不吃海鮮、不想走太多路、想加抹茶體驗），對話累積的是**別人拿不到的行為資料**。
- 修改後行程即時生效，體驗接近「有個真人旅遊顧問隨侍在側」。

### 7. KKday 商品搜尋整合 ＝ 供給面的天然優勢
- 純外部 AI（ChatGPT 等）能排行程，但**排完就結束了**——它沒有可訂購的供給。我們的行程每個景點直接接站內商品庫，「看到 → 想要 → 下單」在同一個畫面完成。

## 五、後續延伸方向（提案）

### A. 客製化與顧客關聯（讓旅伴「越來越懂你」）
- **整合站內行為資料**：瀏覽記錄、收藏清單、歷史訂單、搜尋記錄，都餵給旅伴作為規劃依據——「上次你收藏的那間天空之森餐廳，我幫你排進 Day 2 了」。
- **測驗結果長期化**：旅行 DNA 不只是一次性結果，成為使用者的長期偏好檔案（travel profile），每次規劃自動套用。
- **對話記憶**：使用者在對話中透露的偏好（過敏、帶長輩、蜜月）跨 session 記住，下次規劃不用重講。
- **理解度系統**（UI 已預留「即將推出」）：把「旅伴有多懂你」量化成可見的進度，驅動使用者主動餵更多偏好（玩測驗、多聊天）——遊戲化的資料收集。

### B. 差異化分級與成本控制（減少初期 Token 消耗）
- **高端客戶優先**：黑鑽、白金以上會員優先開放，AI 規劃成本花在 LTV 最高的客群；同時「專屬 AI 旅遊顧問」本身就是高端會籍的權益賣點。
- **精準圈選試點對象**：例如圈選 1,000 位買過東京行程的用戶開放「從訂單排行程」，客群明確、成效好衡量、成本可控。
- **高獲利商品組合優先曝光**：行程景點對應多個商品時，優先呈現高毛利或策略性商品組合。
- **熱門行程模板快取**：定期批次生成熱門目的地的「既定行程模板」（東京五日、大阪親子…）作為快取——多數使用者的需求其實高度重疊，模板 + 個人化微調的混合模式可大幅降低 token 成本，回應速度也更快。
- **分層模型策略**：開場白、簡單問答用便宜快速的模型，完整行程生成才用高階模型（後端已採此設計）。

### C. 整包旅程（Package）整合
- **飯店、機場接送、交通、餐飲全串接**：目前行程以景點/體驗為主，下一步把住宿、機接、交通票券、餐廳預訂全部納入，讓 agent 針對「整趟旅程的每個環節」都去站內找對應商品——一個行程 = 一張完整的購物清單。
- **一鍵成團**：行程確認後「整趟加入購物車」，把規劃到下單的距離縮到一步。
- **行程中服務**：出發後依行程進度推播（「明天要去環球影城，門票 QR code 在這」「這附近有你會喜歡的甜點店」），旅伴從「規劃工具」變成「旅程中的隨行助理」。

### D. 獨立行程規劃 Agent
- 把行程規劃能力抽成**獨立的 Agent 服務**：可多輪自主決策（查商品庫存、比價、檢查營業時間、計算交通時間）而非單次生成，行程品質與可執行性大幅提升。
- Agent 化後可對外輸出：B2B 提供給旅行社、企業差旅；或作為 API 開放給合作夥伴，成為新的收入線。

### E. 我們能做、純外部 AI 做不到的事（核心護城河）
外部 AI（ChatGPT、Gemini）永遠拿不到的東西，正是我們 Agent 的獨占燃料：

| 獨占資料 | 外部 AI | KKday Agent |
|---|---|---|
| 使用者訂單與即將出發的旅程 | ❌ | ✅ 主動從訂單發起規劃 |
| 站內瀏覽、收藏、搜尋記錄 | ❌ | ✅ 規劃時自動納入 |
| 旅行 DNA 測驗結果與對話累積的偏好 | ❌ | ✅ 越用越準 |
| 站內商品庫（庫存、價格、組合、即時可訂） | ❌ | ✅ 行程直接可下單 |
| 會員等級與消費行為模式 | ❌ | ✅ 分級服務與精準推薦 |

結論：**外部 AI 能給「一份看起來不錯的行程」，只有我們能給「一份屬於你、而且現在就能訂的行程」。** 這就是必須自建 Agent 的理由。

### F. 其他優化提案（補充）
- **社群行程牆**：像測驗社群牆一樣，開放使用者分享自己排好的行程，別人可以「一鍵複製再微調」——UGC 帶動供給側內容，也降低生成成本（複製 > 重新生成）。
- **多人共編行程**：和同行者共享行程連結，一起和旅伴討論修改（家庭遊/朋友出遊決策往往是多人的）。
- **價格與庫存感知**：行程生成時檢查商品即時價格與庫存，「這個時段的門票快賣完了」製造急迫感、提升轉換。
- **淡旺季/天氣調整**：結合出發日期的季節與天氣預測，「你去的那週是雨季，我把戶外行程集中在前兩天」。
- **行程後回饋閉環**：旅程結束後旅伴主動關心「這趟玩得如何？」，收集評價回饋到偏好檔案，同時自然引導寫商品評論（解決評論量不足問題）。
- **再行銷觸點**：儲存行程但未下單的使用者，是意圖最明確的再行銷名單——「你排的大阪行程，Day 2 的環球影城門票這週有優惠」。

## 六、小結

AI 旅伴的定位不是「多一個聊天機器人」，而是把 KKday 從「旅遊商品貨架」升級為「旅遊決策夥伴」：

1. **Phase 1** 用角色與測驗建立關係、取得偏好、帶動傳播——入口與資料層。
2. **Phase 2** 用行程規劃把決策過程留在站內，讓每個行程項目都是導購入口——轉換層。
3. **下一步** 用站內獨占資料（訂單、行為、偏好）建立外部 AI 無法複製的個人化 Agent，並以分級開放與模板快取控制成本——護城河與規模化。
